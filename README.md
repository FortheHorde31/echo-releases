# Project Echo

**Запись встреч, расшифровка и диктовка на вашем компьютере.**

Echo записывает разговор, превращает речь в текст и разделяет реплики по голосам.
Помогает вернуться к решению на встрече, расшифровать готовую запись или надиктовать
текст в рабочее приложение. Распознавание работает локально на Mac и Windows.
Бот в звонке не нужен.

**[Скачать для Mac](https://github.com/FortheHorde31/echo-releases/releases/latest)** ·
**[Скачать для Windows](https://github.com/FortheHorde31/echo-releases/releases/latest/download/ProjectEcho-win-x64-Setup.exe)** ·
[Что нового](https://github.com/FortheHorde31/echo-releases/releases)

Бесплатно на время беты, в том числе для компаний. Регистрация не нужна.
В текущих сборках после 7 дней нужен код активации —

## Что можно делать в Echo

| Задача | Как помогает Echo |
| --- | --- |
| **Записать встречу** | Сохраняет микрофон и звук собеседников в Zoom, Google Meet, Teams, Телемосте и других приложениях. Показывает черновик текста во время разговора. После остановки делает итоговую расшифровку с разделением по голосам. |
| **Расшифровать аудиофайл** | Импортирует готовую запись и обрабатывает её теми же моделями, что и встречу. Подходит для интервью, лекций и голосовых заметок. |
| **Надиктовать текст** | По горячей клавише записывает речь и вставляет текст туда, где стоит курсор: в письмо, документ, мессенджер или редактор кода. Диктовки остаются в истории. |
| **Вернуться к разговору** | Хранит записи по проектам и папкам. Позволяет искать по тексту, слушать запись, копировать и сохранять расшифровку в Markdown. |
| **Получить выжимку** | Готовит краткое содержание встречи через выбранного ИИ-провайдера по вашему API-ключу. Это отдельная облачная функция. |

Для русской речи есть **GigaAM v3**, для многоязычной — **NVIDIA Parakeet v3**.
Модели скачиваются один раз. После загрузки запись, расшифровка и диктовка
работают без интернета в пределах действующего пробного периода или активации.

## Встречи в работе ИИ-агента

Через **MCP** можно подключить Echo к Claude Code, Codex, Cursor и другим
совместимым клиентам. Агент сможет найти встречу, прочитать расшифровку
и выжимку, найти нужные реплики и использовать их в вашей работе.

Например: «Найди последнюю встречу по проекту и выпиши, о чём договорились».

Подключение — в **Настройки → MCP**. Доступ включаете вы.
Можно оставить только чтение. Возможности редактирования зависят от платформы.
Данные, которые агент прочитал, обрабатываются по настройкам его клиента
и выбранной модели.

На **Mac** также доступны:

- **Обнаружение встреч.** Echo может предложить запись или начать её сам,
  когда замечает звонок. Функция включается отдельно в настройках.
- **Объединение записей.** Две части разговора можно собрать в одну встречу
  и расшифровать вместе. Исходные записи сохраняются.
- **Задачи.** Проекты, сроки, список на сегодня и добавление голосом.
  Доступность модуля зависит от кода активации.

## Где обрабатываются данные

- **Распознавание — на вашем компьютере.** По умолчанию звук обрабатывают
  локальные модели. Записи и расшифровки хранятся в выбранной вами папке.
- **ИИ-выжимки — по вашему выбору.** Если подключить Anthropic, OpenAI
  или OpenRouter, текст встречи отправляется выбранному провайдеру
  по вашему ключу после согласия. Для этой функции нужен интернет;
  использование API оплачивается отдельно по условиям провайдера.
- **Сервер компании — отдельный режим.** Echo можно настроить на обработку
  аудио на сервере вашей организации. Для подключения напишите разработчику.
- **Служебные запросы.** Приложение обращается в сеть для загрузки моделей,
  обновлений и активации. Счётчики использования без содержимого встреч
  можно отключить в настройках.

Подробнее: [политика конфиденциальности](https://projectecho.pro/privacy).

## Установка

### Mac

**macOS 14.4 и новее · Apple Silicon (M1 и новее).**

1. Откройте [последний релиз](https://github.com/FortheHorde31/echo-releases/releases/latest)
   и скачайте файл `.dmg` в разделе **Assets**.
2. Откройте DMG и перетащите **Project Echo** в папку **Программы**.
3. Запустите Echo. Приложение подписано и нотарифицировано Apple.
   При первом запуске подтвердите стандартный запрос macOS.
4. Дайте доступ к микрофону. Для записи собеседников разрешите захват
   системного звука, для вставки диктовки — Универсальный доступ.
   Echo записывает звук, без видео экрана.
5. Выберите язык и скачайте модель распознавания.

Версия для Mac с процессором Intel не выпускается.

### Windows

**Windows 10 или 11 · x64 (Intel или AMD).**

1. Скачайте [ProjectEcho-win-x64-Setup.exe](https://github.com/FortheHorde31/echo-releases/releases/latest/download/ProjectEcho-win-x64-Setup.exe)
   и запустите установщик.
2. При первом запуске выберите локальную обработку, язык и скачайте модели.
3. Назначьте сочетание клавиш для диктовки в настройках.

Установщик пока без цифровой подписи, поэтому SmartScreen может показать
предупреждение. Сверьте источник: официальный файл размещён в
[релизах этого репозитория](https://github.com/FortheHorde31/echo-releases/releases).

На Windows доступны запись встреч, живой текст, импорт аудио, диктовка,
GigaAM, Parakeet, разделение по голосам, ИИ-выжимки и MCP.
Задачника, обнаружения встреч и объединения записей пока нет.
